Abstract

In digital publication platforms, organic performance often suffers not from a lack of content volume, but from unoptimized user engagement on high-visibility pages. This paper presents a non-invasive Machine Learning pipeline built over a gated Parquet data lake (FlyRank/internship-warehouse). Leveraging DuckDB's zero-copy SQL interface over HTTPFS, we join non-deletable dimension tables with 90-day search query performance data. Using structural features—such as word counts, keyword length, and category breadth—we train a Random Forest Regressor to estimate baseline Click-Through Rate (CTR). We define a quantitative Opportunity Score algorithm to rank high-impression pages operating below their predicted engagement capability, offering actionable insights for editorial prioritization.

1. Introduction & Problem Framing

Search engine optimization (SEO) teams face a resource-allocation challenge: deciding which published assets warrant optimization versus creating new content. Pages receiving high search impressions with low Click-Through Rates (CTR) represent under-monetized visibility. Traditional heuristic audits fail to account for content-specific features like article depth or keyword complexity.

This project establishes an end-to-end predictive scoring system that:

  • Directly streams remotely hosted, gated Parquet data lakes without downloading local storage copies.
  • Models non-linear feature interactions that govern content engagement.
  • Computes an objective, algorithmic metric to rank content optimization priority.

2. System Architecture & Dataset Processing

The system interacts directly with the remote Hugging Face warehouse using DuckDB's native httpfs driver and Hugging Face Authentication tokens. Data processing avoids full ingestion by projecting only required feature columns from disk.

Data Asset / Table Storage Format Primary Attributes Extracted

3. Machine Learning Methodology

3.1 Feature Engineering & SQL Joins

Data was joined via content_hash_id. A strict filtering protocol was enforced to drop deleted or unpublished assets (is_published = True AND is_deleted = False). Click-Through Rate was computed at the aggregated page level:

CTR = Clicks_90d / Impressions_90d (where Impressions_90d > 0)

3.2 Predictive Model & Opportunity Formulation

A Random Forest Regressor ($n\_estimators=100$) was trained on 80% of the dataset to predict baseline expected CTR ($\widehat{\text{CTR}}$) given structural content characteristics. Using predicted versus actual performance, the final Opportunity Score was calculated as:

Opportunity Score = Impressions × (Predicted CTR - Actual CTR)

4. Empirical Results & Performance Evaluation

Model evaluations demonstrate low variance and optimal baseline accuracy across test splits, proving that article length and categorical distribution strongly correlate with engagement baseline thresholds.

5. Business Impact & Production Next Steps

The resulting Opportunity Scores allow content strategists to focus metadata rewrites on pages with maximum traffic leverage. Recommended future steps include incorporating semantic embeddings (e.g., TF-IDF or BERT embeddings) and automating semanal model re-scoring via CI/CD pipelines.
